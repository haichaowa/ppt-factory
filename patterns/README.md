# patterns/ — 布局模式库

回答"一页放什么"。每个模式 = 一个自包含 HTML 片段，装配时**逐字复制**进 deck，只改内容槽位。

## 文件规范

- 每个片段 ≤80 行 = 注释头（用途 / 槽位 / 变体说明）+ 纯 HTML 结构
- 样式全部集中在 `patterns.css`（`.pat-{name}` 前缀类），装配时**整文件内联一次**——片段内**禁止**出现 `<style>` 或内联样式
- 槽位用 `<!-- SLOT: xxx -->` 注释标记，装配时只改槽位内容

## 内容特征 → pattern 速查表（大纲阶段选型依据）

| 内容特征 | pattern | 说明 |
|---------|---------|------|
| 演讲标题 + 副标题 | `cover` | 封面页 |
| 全场核心主张 + 期望行动 | `claim` | 论证锚点页 |
| 问题 / 张力 / 转折 / 行动 | `narrative-map` | 叙事路线总览 |
| 一个结论 + 一张证据图 | `assertion-evidence` | 论证页首选：主张句标题 + 证据图 + 读图路径 |
| 章节切换 / 编号 | `section` | 大字章节分隔 |
| 观点 + 3-5 论据 | `bullets` | 仅用于同级论点，不用于替代证据图 |
| 对比 / 优缺点 / 方案取舍 | `two-col` | 双栏卡片对比 |
| 关键数据 / 成绩 | `metrics` | 大数字 + 说明（数据必须有出处） |
| 演进 / 版本 / 历史 | `timeline` | 纵向时间线 |
| 步骤 / 流程 / 管道 | `steps` | 横向步骤卡 + 箭头 |
| 金句 / 引用 / 观点强调 | `quote` | 引用页 |
| 代码讲解 | `code` | 代码块 + 行高亮（支持 fragment） |
| 参数 / Benchmark 对比 | `table` | 表格 |
| 截图 / 图文说明 | `image-text` | 图文混排（图 base64 内联） |
| 致谢 / 联系方式 / 二维码 | `end` | 结尾页 |

## 使用铁律

1. `assertion-evidence` 的标题必须写结论，证据必须有来源；无证据时禁止使用该模式。
2. `narrative-map` 只用于叙事总览，每阶段 ≤16 字；不能当作四段正文卡片硬塞。
3. `bullets` 只承载同级论点；若论点之间存在因果 / 流程 / 对比，改用 `assertion-evidence` / `steps` / `two-col`。
4. 卡片 ≤4 个；narrative-map 的转折与行动必须有视觉层级差异，禁止等权卡片墙。
5. 素材没有出处时，不得选择 `metrics` / `table` / `assertion-evidence` 的数据图版本。

## 扩展方式

新 pattern = 片段 `.html`（≤80 行）+ `patterns.css` 加 `.pat-{name}` 样式 + 本表加一行。`patterns.css` 总量预算 ≤500 行；超预算时优先拆分低频模式出库，而不是涨预算。
