# CONTENT-RULES — 内容组织规则

## 核心原则（必须）

1. **一页一观点**：每页只传达一个核心观点；观众一次只能记住 3-5 个要点
2. **金字塔原理**：结论先行 → 以上统下 → 归类分组
3. **少即是多**：每页正文 ≤50 字；要点 3-5 条；留白呼吸

## 时长 → 页数（必须遵守）

| 演讲时长 | 推荐页数 |
|---------|---------|
| 3-5 分钟 | 6-10 页 |
| 5-10 分钟 | 10-15 页 |
| 10-20 分钟 | 15-25 页 |
| 20-40 分钟 | 25-45 页 |

## 标准结构

```
封面（1）→ 目录（可选 1）→ 章节 ×N（section 1 页 + 内容 n 页）→ 总结（1）→ 结尾（1）
```

## 大纲模板（WORKFLOW 第 2 步的产出格式）

```
1. cover    — 主标题 / 副标题
2. section  — 章节标题
3. bullets  — 观点（要点数、是否 fragment）
4. metrics  — 数据点（注明数据出处）
...
N. end      — 致谢 / 联系方式
```

pattern 选型查 `patterns/README.md` 速查表。

## 内容密度

| 演讲类型 | 密度 | 说明 |
|---------|------|------|
| 教程 | 中 | 步骤清晰，留白适当 |
| 分享 | 中高 | 信息量大，节奏快 |
| 产品 | 低 | 视觉为主，文字精简 |
| 技术 | 中高 | 代码 + 解释结合，代码页必须有讲解视角（高亮/注释） |

## 数据纪律（必须）

**禁止编造数据。** 所有数字必须有出处：用户提供的材料、或可公开验证的来源。没有可靠数据就不用 metrics / table 页——宁可留白，不可造假。

## 检查清单

- [ ] 每页一个观点，正文 ≤50 字
- [ ] 列表项 3-5 条，有 fragment 节奏
- [ ] 标题简洁有力（≤12 字为佳）
- [ ] 有封面和结尾页，章节分隔清晰
- [ ] 页数与时长匹配
- [ ] 所有数据有出处
