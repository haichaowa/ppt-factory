# CONTENT-RULES — 内容组织规则

> 所有引擎共用。生成大纲前先完成 `docs/AUDIENCE-BRIEF.md`；设计依据见 `docs/DESIGN-RESEARCH.md`。

## 核心原则（必须）

1. **一页一主张**：每页只传达一个可被证据支持的观点；论证页标题优先写结论，不写“背景 / 对比 / 结果”这类主题词
2. **金字塔原理**：核心主张 → 分组论点 → 证据；上层概括下层，不许出现与主张无关的页面
3. **低认知负荷**：每页只引入一个新概念、一个图表焦点或一个决策权衡；复杂流程必须拆页或渐进揭示
4. **少即是多**：每页正文 ≤50 字；要点 3-5 条；留白用于分组和引导视线
5. **证据优先**：数字、截图、图表必须说明来源；视觉是证据，不是装饰

## 时长 → 页数（必须遵守）

| 演讲时长 | 推荐页数 |
|---------|---------|
| 3-5 分钟 | 6-10 页 |
| 5-10 分钟 | 10-15 页 |
| 10-20 分钟 | 15-25 页 |
| 20-40 分钟 | 25-45 页 |

## 标准结构

```
封面（1）→ 核心主张（可选 1）→ 目录（可选 1）→ 章节 ×N（section 1 页 + 内容 n 页）→ 风险/边界（推荐 1）→ 总结（1）→ 行动/结尾（1）
```

结构必须对应 `AUDIENCE-BRIEF` 选择的叙事线，不允许把所有材料按章节顺序平铺。

## 叙事骨架（必须先选一条）

| 叙事线 | 最小骨架 |
|---|---|
| decision | 问题 → 约束 → 选项 → 取舍 → 建议 → 下一步 |
| teaching | 已知场景 → 新概念 → 示范 → 练习 / 误区 |
| technical-review | 目标 → 现状 → 方案 → 权衡 → 验证 → 风险 |
| product-story | 用户处境 → 冲突 → 方案 → 体验差异 → 证明 |
| research | 问题 → 方法 → 发现 → 解释 → 局限 → 意义 |

## 大纲模板（WORKFLOW 第 2 步的产出格式）

```
1. cover               — 主标题 / 副标题 / 场合与日期
2. claim               — 核心主张（一句完整话 + 期望行动）
3. narrative-map       — 问题 → 张力 → 转折 → 行动（可选）
4. section             — 章节标题或本章结论
5. assertion-evidence  — 主张句 + 证据图 / 证据摘要 / 出处
6. bullets             — 支撑论点（要点数、是否 fragment）
7. metrics             — 数据点（注明数据出处）
...
N. end                 — 回收主张 + 下一步行动 / 联系方式
```

大纲每行必须包含：**pattern、主张句标题、证据、出处、fragment 节奏**。没有证据的论证页，只能用 quote / section / narrative 过渡，不得伪装成结论页。

pattern 选型查 `patterns/README.md` 速查表。

## 内容密度

| 演讲类型 | 密度 | 说明 |
|---------|------|------|
| 教程 | 中 | 步骤清晰，留白适当 |
| 分享 | 中高 | 信息量大，节奏快 |
| 产品 | 低 | 视觉为主，文字精简 |
| 技术 | 中高 | 代码 + 解释结合，代码页必须有讲解视角（高亮/注释） |

## 数据纪律（必须）

**禁止编造数据。** 所有数字必须有出处：用户提供的材料、或可公开验证的来源。没有可靠数据就不用 metrics / table 页——宁可留白，不可造假。

图表必须回答观众问题，而不是展示原始数据。每张数据页先写：

1. 图表要支持的**主张句**
2. 观众第一眼应看到的**信号**
3. X / Y 或分类的含义
4. 反常识点、限制条件、数据出处

不确定区间、样本范围、统计口径、异常点若影响结论，必须呈现或写入备注。

## 检查清单

- [ ] Audience brief 已完成，核心主张是一句完整话
- [ ] 叙事线明确，页面顺序服务主张而不是素材顺序
- [ ] 每页一个主张，正文 ≤50 字
- [ ] 论证页标题优先写结论；主题词标题只出现在 cover / section / 目录
- [ ] 列表项 3-5 条，句式平行，有 fragment 节奏
- [ ] 每页能通过 3 秒测试：先看什么、证明什么、再看什么
- [ ] 有封面、风险/边界、总结、结尾行动
- [ ] 页数与时长匹配
- [ ] 所有数字和图表有出处
- [ ] 术语按观众已知 / 未知处理，首次出现有解释或示例
