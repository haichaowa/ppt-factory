# DESIGN — 设计规范

## 设计令牌

主题变量 schema 的唯一权威定义在 `templates/base/themes/README.md`。所有视觉定制**只**通过主题变量，禁止在 deck 里散落硬编码颜色/字号。

## AI Native 文档原则（写规范时遵守）

- 用"必须 / 禁止"式约束句 + 正反示范，不用散文说理
- 机器可读优先：表格数据优于段落
- 变更必须同步受影响文件并在 `docs/LESSONS.md` 记录

## 中文排版规则（必须）

| 规则 | 要求 |
|------|------|
| 行首禁则 | 行首不得出现 `，。、；：？！）〕》」』%` 等标点 |
| 行尾禁则 | 行尾不得出现 `（〔《「『` |
| 中西文间距 | 中文与英文/数字之间留空隙（如"使用 Claude Code 生成"） |
| 行高 | 由主题变量显式声明（`--line-height-*`）——跨平台字体度量差异是溢出主因 |
| 字号 | px 级显式声明，由 `base.css` 字号阶梯统一管理；禁止 rem/em 相对链 |
| 密度上限 | 每页正文 ≤50 字；列表 ≤5 条；patterns 预留 8-10% 高度安全余量 |

## 对比度（必须）

正文 ≥ WCAG AA 4.5:1；大字标题（≥32px）≥ 3:1。深色主题弱化文字（`--fg-dim`）不得低于 4.5:1。

## 图片素材规范

| 类型 | 要求 |
|------|------|
| 内联 | 必须 base64 data-URI；单图压缩至 ≤200KB（超出先降分辨率/质量） |
| 截图 | 宽 ≤1200px，PNG |
| 照片 | JPEG 质量 80 |
| 二维码 | ≥240×240px，四周留白 ≥16px（扫码可靠性），白底黑码；投屏场景可加 `filter: brightness(1.2)` |

## 反 AI-slop 清单（禁止）

1. 禁止"紫蓝渐变背景 + 白字大标题"的 AI 风封面套路
2. 禁止全居中布局贯穿全篇（cover / section / quote 除外）
3. 禁止等大等距的卡片墙堆满一页（卡片 ≤4 个，允许层级差异）
4. 禁止与内容无关的装饰性 emoji / 图标填充
5. 禁止编造数据填充 metrics / table 页
6. 禁止引用在线字体 CDN；字体只用主题声明的系统栈
7. 禁止每页换配色制造"丰富感"——一稿一个主题，强调色克制使用
