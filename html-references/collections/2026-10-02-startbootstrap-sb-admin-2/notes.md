# SB Admin 2 · 体系拆解笔记

> 归档版本：4.1.4 · commit `f0309881ef82794a1bd6257cd321801bc38a0f3d`。
> 本文只描述和提炼外部源码，不修改 `source/`。

## 1. 快速判断

SB Admin 2 是一个成熟的 **后台信息系统模板**，不是营销页模板。它的核心价值在于：把大量异构信息（KPI、趋势、比例、项目进度、密集表格、通知、账户操作）统一到同一套卡片容器、左侧导航、顶栏操作区和颜色语义中。对 PPT Factory 的价值主要是 **信息组织与数据型版式**，不是戏剧化视觉叙事。

## 3. 组件/结构完整清单

### 3.1 应用框架

- **页面包裹**：`#wrapper` 横向 flex；`#content-wrapper` 纵向 flex 并填满剩余宽度；`#content` 承载主内容。
- **侧栏**：`ul.navbar-nav.bg-gradient-primary.sidebar.sidebar-dark.accordion`；品牌、分组标题、可折叠菜单、当前态、收起按钮、升级卡片。
- **侧栏尺寸**：桌面展开 14rem；收起 6.5rem；移动端折叠为 0。菜单项左右 1rem padding，分组标题 0.65rem。
- **顶栏**：高 4.375rem，白底 + shadow；搜索、通知、消息、用户菜单、分隔线。
- **内容页脚**：`footer.sticky-footer`，上下 2rem，版权行 0.8rem；由 flex 布局避免异常高度。
- **全局弹层**：右上滚动回顶按钮、退出登录确认 modal。

### 3.2 导航组件

- 主导航当前项：蓝色背景 + 白字 + 700 字重。
- 二级菜单：移动端为绝对定位浮层 + `$box-shadow` + grow-in；桌面展开在侧栏内部，无边框无阴影。
- 分组标题：0.65rem、800、全大写、弱白透明度。
- 下拉箭头：Font Awesome `f105/f107` 替代默认三角，视觉更圆润。
- 通知中心：全宽移动端菜单；≥576px 收窄到 20rem，含色条、头像、时间、状态点。
- 消息中心：头像、发件人、摘要、时间、内边框，形成轻量收件箱。
- 用户菜单：头像 + 姓名 + 下拉资料/设置/退出。

### 3.3 卡片体系

- **基础卡**：白底、0.35rem 圆角、浅边框、`0.15rem 1.75rem` 大范围轻阴影；卡头 `gray-100`。
- **KPI 卡**：`h-100 py-2` + 左侧 0.25rem 色条 + `row no-gutters align-items-center`，左文右图标；标签 `text-xs uppercase`，数值 `h5 bold gray-800`。
- **图表卡**：卡头标题 + 右上 no-arrow 下拉；卡体放置 canvas。
- **进度卡**：项目名 + 时间/预算元信息 + 小进度条；不同语义色区分状态。
- **色板卡**：主题色背景、白色标题、`white-50` 小号 HEX 值。
- **可折叠卡**：卡头可点击，右侧 chevron 随折叠状态旋转；卡头右保留 3.25rem 命中区。
- **认证卡**：左右分栏，左侧远程图片，右侧白色表单卡；圆角 0.35rem。
- **插画卡**：SVG 插画 + 标题 + 说明 + CTA，用于推广/解释内容。

### 3.4 数据展示

- **面积图**：`.chart-area` 移动 10rem，≥768px 20rem。
- **柱状图**：与面积图同一高度规则，保证图表模块可互换。
- **环形图**：移动 15rem，≥768px `calc(20rem - 43px)`，补偿图例差异。
- **表格**：DataTable 的搜索、排序、每页条数、分页；状态徽标用色彩语义。
- **小进度条**：`.progress-sm` 高 0.5rem。
- **徽标 / 计数器**：导航角标缩放 0.7，定位在图标右上。

### 3.5 表单与按钮

- 认证输入：0.8rem 字号、10rem 圆角、`1.5rem 1rem` padding，形成高触达胶囊输入。
- 登录/注册按钮：0.8rem 字号、10rem 圆角、`0.75rem 1rem` padding。
- 品牌按钮：Google `#ea4335`、Facebook `#3b5998`，白字。
- 圆形按钮：默认 2.5rem，小 1.8rem，大 3.5rem。
- 图文分离按钮：左侧半透明黑色图标区 + 右侧文字区，整体无圆角，依靠色块分割。
- 常规按钮继承 Bootstrap 4 尺寸和语义色。

### 3.6 工具类与动效

- 主题渐变：180deg，主色 10% 到 darken 15% 100%。
- 灰阶文字/背景：`gray-100` 到 `gray-900`。
- 左/下彩边：0.25rem 实线，按主题色循环。
- 文字字号：`text-xs` 0.7rem，`text-lg` 1.2rem。
- Grow In：0.9 → 1 缩放 + 0 → 1 透明度，200ms，轻回弹。
- Fade In：0 → 1 透明度，200ms。
- 溢出工具 `.o-hidden`、小进度 `.progress-sm`、旋转 ±15deg、无箭头下拉。

## 4. 设计系统拆解

### 4.1 色板

**主题语义色**

| Token | 值 | 用法 |
|---|---|---|
| `primary` / `blue` | `#4e73df` | 主导航渐变、链接、当前态、主按钮、品牌强调 |
| `secondary` | `#858796` | 次级信息与中性操作 |
| `success` | `#1cc88a` | 收入、完成、正向状态 |
| `info` | `#36b9cc` | 任务、提示型数据 |
| `warning` | `#f6c23e` | 待处理、请求、注意 |
| `danger` | `#e74a3b` | 支出、错误、高风险 |
| `light` | `#f8f9fc` | 页面底色和浅背景 |
| `dark` | `#5a5c69` | 深色文字/深色组件 |

**灰阶**

`#f8f9fc`、`#eaecf4`、`#dddfeb`、`#d1d3e2`、`#b7b9cc`、`#858796`、`#6e707e`、`#5a5c69`、`#3a3b45`。灰阶偏蓝紫，与主蓝形成同冷暖关系；页面背景不是纯灰，因此卡片白底仍能被区分。

**品牌色**：Google `#ea4335`、Facebook `#3b5998`。它们只用于社交登录，不进入通用主题色循环。

**渐变规则**：所有主题色可通过 `bg-gradient-*` 生成 180deg 轻渐变；侧栏实际使用 `bg-gradient-primary`。渐变是身份层，不用于所有容器。

### 4.2 字体

- 主字体：Nunito，Google Fonts 外链，包含 200–900 多档字重。
- 回退栈：`-apple-system`、BlinkMacSystemFont、Segoe UI、Roboto、Helvetica Neue、Arial、sans-serif。
- 等宽栈：SFMono-Regular、Menlo、Monaco、Consolas、Liberation Mono、Courier New。
- 正文：1rem / line-height 1.5 / color `gray-600`。
- 标题：H1 2.5rem、H2 2rem、H3 1.75rem、H4 1.5rem、H5 1.25rem、H6 1rem；标题字重被覆盖为 400，靠字号与颜色建立层级。
- 小字号族：0.65rem 导航分组、0.7rem `text-xs`、0.75rem 辅助文本、0.8rem 认证表单、0.85rem 侧栏菜单/搜索/下拉、0.875rem 常规小按钮。
- 权重语言：400 正文/标题，700 当前态与关键数字，800 分组/品牌，900 图标箭头。Nunito 的圆润字形与高字重支撑了这套轻快的 SaaS 气质。

### 4.3 间距与布局

- 基础 spacer：1rem；grid gutter 为 1.5rem。
- 常用卡片：`mb-4` 卡片间 1.5rem；卡体通常 1.25rem；KPI 卡 `py-2`。
- 侧栏：展开 14rem、收起 6.5rem；菜单项桌面 1rem padding。
- 顶栏：4.375rem 高；图标按钮 2.5rem；头像 2rem。
- 图表：移动 10rem，桌面 20rem；环形图补偿 43px 图例高度。
- 页脚：上下 2rem。
- 断点：576 / 768 / 992 / 1200px；仪表盘主区常用 `col-xl-8 col-lg-7` + `col-xl-4 col-lg-5`，KPI 用 `col-xl-3 col-md-6`。
- 阴影：小阴影 `0 0.125rem 0.25rem rgba(gray-900,.2)`；主卡片 `0 0.15rem 1.75rem rgba(gray-900,.15)`。阴影偏大但透明度低，形成“悬浮但不重”的效果。

### 4.4 圆角与线条

- 基础圆角 0.35rem，比 Bootstrap 默认 0.25rem 更柔。
- 圆形按钮和图标容器使用 100% 圆角。
- 认证表单 10rem 圆角，形成胶囊。
- 边框色由 `gray-200` 加深 2% 生成，介于背景与输入框之间。
- KPI 左色线和彩色 left/bottom border 均为 0.25rem，是最低成本的语义编码。

### 4.5 图标与插画

- Font Awesome 5 Free 本地字体/样式已随源码提交，主界面离线可用。
- UnDraw SVG 插画本地保留，线性、圆角、单一主题色，与 Nunito 气质一致。
- 认证页背景使用远程 Unsplash URL，是本档案的主要离线风险。

## 5. 这套体系为什么成立

1. **容器先于内容**：所有复杂内容先进入同一张白卡，再通过卡头、边线、图表、表格等插槽分化。即使信息类型很多，页面仍保持统一边界和间距。
2. **语义色稳定复用**：蓝=主品牌/交互，绿=收入/完成，青=任务/提示，黄=待处理，红=支出/风险。色、边线、按钮、进度条共享同一套 token，用户学习一次即可理解全站。
3. **导航与内容分层清楚**：深蓝渐变侧栏承担全局定位，白底顶栏承担搜索和通知，浅灰内容区承担信息消费。三个区域用色彩和阴影分离，不互相竞争。
4. **文档化工具类**：颜色、边线、动效、杂项不是散落在样式里的魔法，而是独立页面可查；这让模板从“页面集合”升级为“可扩展系统”。
5. **响应式策略简单可靠**：卡片列从 `xl:3 / md:6` 到移动单列；图表固定两档高度；侧栏从展开到图标再到隐藏。变化点少，行为可预期。
6. **细节有品牌感但不过度**：Nunito 圆润字体、偏蓝灰阶、轻渐变、大而透明的阴影共同形成友好 SaaS 风格；动效只有 200ms grow/fade，服务于状态出现而非炫技。

## 6. 局限与风险

1. **技术栈较旧**：Bootstrap 4.6、jQuery 3.6、Chart.js 2.9、DataTables 1.10；适合研究版式与信息组织，不建议直接引入新项目。
2. **演示美学偏后台**：标准卡片、侧栏和密集表格适合业务汇报，不适合需要强舞台感、品牌张力或叙事节奏的 keynote。
3. **离线不完整**：Nunito 和认证页背景依赖 Google Fonts / source.unsplash.com。字体有系统回退，视觉会变化；认证页背景断网时缺失更明显。
4. **可访问性有历史缺口**：`a:focus { outline: none; }`、多处 `:focus { outline: none; }` 会削弱键盘可见性；`aria-expanded` 初始值与 collapsed 状态也存在旧 Bootstrap 模板常见的不严谨处。
5. **内容语义重复**：模板大量复制的占位文本/导航让每个 HTML 约 400–900 行；对学习者容易造成干扰，需要识别哪些是结构性代码。
6. **视觉表现依赖组件库**：卡片、按钮、网格、表格基础来自 Bootstrap；真正自有的增量是 token 覆盖、侧栏/顶栏、KPI 卡、图表容器、认证卡和工具类。
7. **默认字体对比度需复核**：正文 `gray-600 #858796` 在白底上的对比度为 3.56:1，低于 WCAG AA 正文 4.5:1；主蓝 `#4e73df` 为 4.34:1，作为小字号文字也需要谨慎。全套模板还存在 46 处占位 `alt="..."`、34 处折叠菜单初始 `aria-expanded="true"` 与 4 处 SCSS `outline: none`，这些都不应迁移。

## 7. 可直接借鉴的资产

- **KPI 边线卡**：色条 + 超小标签 + 大数字 + 右侧圆形图标，是数据摘要页的稳定原型。
- **8/5 内容图表分区**：主趋势占 7–8 列，比例/辅助图占 4–5 列，适合季度回顾和产品数据页。
- **侧栏信息架构**：Dashboard → Interface → Addons → Pages → Charts → Tables 的分组逻辑，可用于多页 deck 导航模型。
- **彩色边线语义系统**：0.25rem 左边线能以极低成本标记类别，适合列表、引用、步骤、状态说明。
- **工具类文档页**：把颜色、边框、动效、字号做成可视页面，比抽象 token 表更容易被设计师和开发者共同使用。
- **认证三页**：登录、注册、忘记密码保持同一背景图逻辑和卡片结构，是“同族页面保持一致性”的清晰示范。
- **404 glitch**：大数字 + 红蓝错位 + 搜索入口，可用于错误/结尾页的情绪化点缀，但应降低持续动画频率。

### 8.1 patterns/ 逐项映射

### 8.3 PPT Factory 落地取舍

- **优先吸收**：KPI 卡、彩色边线、图表卡、卡片间距、语义色、8/5 分栏、侧栏信息架构、工具类文档方法。
- **谨慎吸收**：大阴影、全站灰蓝背景、Bootstrap 4 class 命名、jQuery 交互、DataTables 控件。
- **不应吸收**：移除 focus outline 的做法、长正文低对比灰色、认证页远程图片依赖、旧依赖栈。
- **主题适配**：若 PPT Factory 生成固定 16:9 静态页面，可把侧栏思想转化为封面/章节页的目录与页码指示，而不是在每张 slide 中保留可滚动侧栏。
