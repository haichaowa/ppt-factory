# web-clones · 高保真网页素材库

**目标 是高质量素材，不是实现方式。** 每天完整归档一个设计出色的网站：
镜像原站、多视口截图、区块高清单、真实设计令牌。风格复刻（原创 HTML 重构）
只是可选深化项，不作为必做交付。

## 与 PPT Factory 的关系

- 归档素材供人工浏览、选型、提炼；
- 设计令牌可作为 `templates/base/themes/` 新主题的候选（人工提炼，不改源码）；
- 拆解结论可反哺 `docs/DESIGN-RESEARCH` 与 `docs/DESIGN`。

## 每日产出结构

```text
web-clones/clones/YYYY-MM-DD-site-slug/
├── archive/       # 原站完整镜像（wget 镜像 / 单文件另存 / DOM 快照）
├── screenshots/   # 1440 / 1280 / 375 三档全页截图
├── sections/      # 关键区块元素级高清单（每张配一句好在哪里）
├── notes.md       # 设计拆解（基于归档页面的真实计算样式）
├── tokens.json    # 结构化设计令牌
├── meta.md        # 来源、抓取方式、时间、版权口径
└── remake/        # 可选：原创文案的风格复刻（加分项，非必做）
```

## 归档方法（按优先级）

1. `wget --mirror --page-requisites --adjust-extension --convert-links` 完整镜像；
2. 动态渲染页用浏览器"另存为单文件"（含资源）；
3. 都失败时降级：多视口截图 + DOM/计算样式快照，并在 meta.md 说明原因。

## 版权口径

- 归档仅供本地学习留存，**不二次分发、不商用**；
- 保留原站版权信息；robots 或条款明显禁止抓取的站点不归档，只做截图与拆解笔记；
- `remake/` 若执行：只学风格，文案/图形原创，不复刻 logo 与版权素材。

## notes.md 必须拆解

- **设计令牌**：主色/辅色/背景/文字的**具体色值**、字号阶梯、字重、行高、圆角、阴影、间距节奏
- **字体系统**：字族、中西文搭配、层级用法
- **版式结构**：网格、留白节奏、视觉层级、首屏构图
- **动效语言**：hover/滚动过渡的时长与缓动参数
- **可复用结论**：这套风格适合什么场景，怎么转化成 PPT 主题或 patterns
