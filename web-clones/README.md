# web-clones · 优秀前端设计复刻库

PPT Factory 的**外部设计参考层**：每天定时搜集一个设计出色的网站，截图存档，
拆解其设计令牌，并用纯 HTML/CSS/JS 复刻视觉风格。长期目标是把优秀网页的
版式、配色、字体、动效语言转化为 PPT Factory 的主题与模式养分。

## 每日产出结构

```text
web-clones/clones/YYYY-MM-DD-site-slug/
├── original.png      # 原站截图（浏览记录）
├── clone.png         # 复刻版截图（尽量对比验证）
├── index.html        # 复刻页面（单文件优先，无构建步骤）
└── notes.md          # 设计拆解笔记
```

## notes.md 必须拆解

- **设计令牌**：主色 / 辅色 / 背景色 / 文字色 / 圆角 / 阴影（写出具体值）
- **字体系统**：字族、字号阶梯、行高、字重、中西文搭配
- **版式结构**：网格、留白节奏、视觉层级、首屏构图
- **动效语言**：hover、滚动、过渡时长与缓动
- **可复用结论**：这套风格适合什么场景，怎么转化成 PPT 主题
  （对应 `templates/base/themes/`）或布局模式（对应 `patterns/`）

## 与 PPT Factory 的关系

- 本目录是**只读参考资产**：复刻产物不直接进入 `decks/`，不修改 `templates/` 与 `patterns/` 源码；
- 人在验收时若发现某套设计令牌值得沉淀，手动提炼到 `templates/base/themes/` 新主题；
- 设计拆解结论可反哺 `docs/DESIGN-RESEARCH` 与 `docs/DESIGN`。

## 复刻原则

1. **学风格，不抄内容**：文案自己写，图片用纯色/渐变/图形替代，不盗用原站资源；
2. 单文件 HTML，双击即可打开，零依赖零构建；
3. 忠实还原布局和气质，允许简化交互；
4. 版权敏感的商标、logo 一律不复刻。
