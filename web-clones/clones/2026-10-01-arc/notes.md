# Arc 首页设计拆解（DOM 实测）

> 证据来自 `archive/viewport-{1440,1280,375}-metrics.json`、`archive/design-evidence.json`、`archive/key-element-metrics.json`。本页不是中性 SaaS 模板，而是“高饱和品牌色 × 编辑排版 × 产品实拍”的组合：钴蓝承担情绪，奶油色负责呼吸，视频负责可信度。

## 1. 大胆配色：三色强对比，而非多色堆叠

- **主品牌蓝**：`#3139FB` / `rgb(49,57,251)`。首屏、Footer、Feature 标题和正文链接共用；在 1440px 页面上作为 text color 出现 118 次，是最强记忆点。
- **深蓝 CTA 色**：`#2702C2` / `rgb(39,2,194)`。用于 Windows 下载按钮和白色按钮上的文字，比主蓝更深，保证白底可读性。
- **奶油纸色**：`#FFFCEC`。迁移横幅与媒体 marquee 背景或前景；用来软化主蓝并带来纸质、编辑感。
- **暖奶油**：`#FFFADD`。首屏辅助文字与浅色按钮。
- **近黑**：`#000000`、灰 `#696969`；白 `#FFFFFF`。信息层保持克制，避免颜色失控。
- 层次可概括为：**主蓝 / 深蓝 / 奶油 / 白**。蓝色既做背景也做文字，减少新色种；高饱和但依靠奶油色留白平衡。
- 实测对比（WCAG 2.1）：`#FFFCEC` on `#3139FB` 6.56:1，`#FFFFFF` on `#2702C2` 11.21:1，`#696969` on `#FFFCEC` 5.33:1，`#FFFADD` on `#3139FB` 6.42:1；8 个关键组合全部通过 AA，最低 6.42:1。

## 2. 字体系统：三套字役明确，品牌字不负责长文

- **品牌大字**：`Marlin Soft SQ`，700。桌面 H1 45.51px / line-height 42.25px / letter-spacing -1.8204px；Feature 标题 40px / 39px / -1.6px；移动 H1 32px / 31.2px / -1.6px，Feature 27.2px / 26.52px / -1.6px。行高略小于 1，形成紧实的海报感。
- **迁移横幅**：`Exposure VAR` 700，36px / 36px / -0.72px，宽度 611.25px；与 Marlin 区分新旧叙事。
- **短说明与 UI**：`InterVariable` 500，17px / 25.5px；Feature body 灰 `#696969`，信息密度低。
- **横幅正文**：`ABC Oracle` 400，20px / 24px，色值 `rgba(0,0,0,.65)`。
- **按钮系统字体**：`-apple-system, system-ui` 600，14px / 29px / -0.14px；下载 CTA 273×45px、圆角 10px、左右成对。
- `archive/design-evidence.json` 记录 38 条 `@font-face`，实际渲染字体已按 URL 补充到 `archive/resources/fonts/`。

## 3. 非对称构图：中央轴心被故意打破

- **首屏**：页面最大宽度 1280px、左右 padding 32px；H1 起点 x=390.64，宽 658.72，接近但不完全居中；产品截图从 y=1099 开始，宽 1470、x=-15，越过 1440 视口，形成溢出式裁切。
- **迁移横幅**：文字中心线 x≈720，但背景图形偏置、图标 CTA 组合和下方 1200px 图像让上下重心错位。
- **Feature 段落**：第一标题 x=340.17、宽 759.66；正文 x=456.97、宽 526.06。两者中心分别约 x=720 / x=720，但边缘严重不对称，视觉上是居中排版与左对齐文本盒的混合。
- **媒体层**：三段视频均为 1440×959.66 的全宽块，交替放置在不同滚动深度，让页面从“模块卡片”变成纵向连续画布。
- **Marquee**：媒体引语以 1440×67 横向滚动，四条重复引语制造节奏，也把第三方背书转成装饰线。

## 4. 间距、圆角与按钮

- 全局变量：`--padding: 32px`、`--max-width: 1280px`、`--navbar-height: 64px`、`--mobile-cta-height: 56px`。
- Feature 大包装 `padding: 128px 0`；每个 feature 内部 gap 8px，标题自身左右 padding 32px，正文 24px。
- Footer CTA `padding: 32px 0 40px`；Footer 导航 `padding: 32px`、gap 43.2px。
- 圆角极少：下载按钮 10px、链接 focus 4px、普通媒体/卡片 8px、Dia 胶囊 CTA 22px。整体是编辑排版而非圆角卡片系统。
- 阴影几乎不承担结构，层级主要依靠色块、文字尺度、媒体边界和留白。

## 5. 动效语言：滚动媒体与轻微交互，不做全站复杂动画

- 双条 `.marquee` `scroll` 动画线性运行，实测 duration 78522.5ms、delay 0、`linear`，低速度、长周期，形成持续漂浮感。
- 常见 hover/状态过渡：`transform 0.15s, background 0.15s`；`background 0.2s ease-in-out`；`transform 0.2s ease-in-out`；`opacity 0.1s ease-out`。交互反馈轻快、低幅度。
- CSS 另有 `k-lFWJD`（translateX -1px→-42px）与 `k-coDfUB`（background-position -800px→800px）两个备用的微位移动画；本次滚动采样中实际处于 running 状态的是两个 `.marquee` scroll 动画。页面叙事主要依赖视频播放与滚动 reveal，而非复杂路径动画；截图捕获时用 reduce motion 固定状态，保证资料可复现。

## 6. 响应式实测

- 三档均无横向溢出：1440 / 1280 / 375 高度分别为 6125 / 5805 / 3601px。
- **1440→1280**：H1 保持 45.51px / 42.25px，最大内容宽度仍 1200px，只是左右安全边从 120px 收缩到 40px；超宽产品截图从 x=-15、宽 1470 变为 x=-32、宽 1344，继续保留裁切张力。
- **375**：H1 降到 32px / 31.2px、宽 337.5px；迁移横幅图像变为 375×216.56，产品视频变为 375×249.91。布局没有简单等比缩小，而是把“全宽画布”策略延续到移动端。
- 移动端文本 inline padding 仍为 32px/24px；全局 `--mobile-cta-height: 56px` 提供固定底部操作区。

## 7. 可复用结论

- 适合转化成 **产品发布页、创作者工具官网、PPT 封面/章节页**：以一两个高饱和品牌色 + 奶油底 + 大号紧排字体建立个性，再用真实产品动态画面增强可信度。
- PPT 转译建议：背景 `#3139FB`，标题 `#FFFCEC` 40–72px 且行高 0.95–1.05，正文 `#696969` 17px；白/奶油色大块留白，不要添加更多主色。
- 版式可用“标题 40px + 正文 17px + 全宽媒体”的节奏；每页只讲一个能力，用真实界面截图替代图标阵列。
- CTA 用白底 `#FFFFFF` + 深蓝 `#2702C2`，10px 圆角、45px 高；按钮不追求夸张渐变，靠底色反差突出。
