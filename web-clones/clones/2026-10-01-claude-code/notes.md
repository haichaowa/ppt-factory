# Claude Code 设计拆解（DOM 实测）

> 证据来源：`archive/style-metrics-{1440,1280,375}.json`、`archive/key-element-metrics.json`、`archive/dom-snapshot.html`。除特别说明外，以下数值均为 1440×960 视口的 Chromium computed style。

## 1. 第一眼结论

Claude Code 不是一个冷色“开发者暗页”，而是用 Anthropic 的暖白编辑气口承接工程产品：外层页面是 `#FAF9F5` 纸感底、`#141413` 墨色文本和大号衬线标题；工程证据则局部切到 `#141413` 深色终端、白色产品 Shell 和 mono 命令。它的高级感来自“大面积留白 + 低饱和墨色 + 精确的深浅分层”，而不是发光、玻璃或强渐变。

## 2. 色彩系统

### 主色 / 背景

| 用途 | 实测值 | 观察 |
|---|---:|---|
| 页面底 | `rgb(250,249,245)` / `#FAF9F5` | 暖白，比纯白柔和，减少长文案刺眼感 |
| 主文字 | `rgb(20,20,19)` / `#141413` | 墨黑而非纯黑 |
| 次级文字 | `rgb(94,93,89)` / `#5E5D59` | 保留足够对比，同时与主文字形成三级关系 |
| 三级 / 界面弱文字 | `rgb(135,134,127)` / `#87867F` | 用于 footer、辅助说明和 app 内弱标签 |
| 白色区块 | `#FFFFFF` | 定价、终端工作区等模块的面板底 |
| 细描边 | `#E8E6DC`、`#F0EEE6` | 暖灰 hairline，几乎只做轮廓，不做装饰 |

### 深色层

| 层 | 实测值 | 用途 |
|---|---:|---|
| 终端卡 | `#141413` | 主体代码实录 |
| 终端标题栏 | `rgb(48,48,46)` / `#30302E` | 与正文区拉开一小级 |
| 深色命令井 | `rgb(26,25,24)` / `#1A1918` | newsletter 内的安装命令 |
| 深色正文 | `#FAF9F5` | 延续页面暖白，而不是刺眼纯白 |
| 终端代码 | `rgb(176,174,165)` / `#B0AEA5` | 降亮度，让代码像过程记录而非营销标题 |

### 语义与代码点缀

页面不依赖强品牌色，但在代码/产品界面内保留少量清晰语义色：蓝 `#1F6FE5`、绿 `#2D8A4E`、红 `#E5484D`、Anthropic 珊瑚 `#D97757`。这些点缀几乎全部被限制在产品界面和终端中，不污染营销排版。

## 3. 字体与字号阶梯

- **正文 / UI**：`anthropicSans, "anthropicSans Fallback", system-ui, sans-serif`，基础 `15px / 22.5px`，400；主要 CTA `17px / 17px`。
- **标题**：`anthropicSerif, Georgia, serif`，大标题 400，小标题 500。衬线字体承担品牌与人文温度。
- **命令**：`anthropicMono, ui-monospace, monospace`，安装命令 `17px / 25.5px`。
- **终端正文**：`ui-monospace, SFMono-Regular, Consolas, Menlo, monospace`，`15px / 22.5px`。

## 4. 版式、网格与留白

- 1440px 桌面页 gutter 为 64px；固定 header 高 129px，与页面同底色。
- 首屏是典型的双栏叙事：左侧 421px 文本列（H1、lead、双 CTA），右侧 843×474 的产品 Shell。两者不是硬 50/50，而是左轻右实。
- 定价三卡各 381px、水平 gap 24px，卡内 padding 32px、flex gap 24px。三张卡高度一致，使 `$17 / $100 / $200` 的视觉锚点整齐。
- 主要 section 底部 padding 128px；newsletter 上下各 128px；footer 约 96px。节奏是“大段落呼吸 + 卡片内紧凑”。
- 页面顺序：hero 产品证明 → 定价 → 新功能 → 代码任务 → 多入口集成 → Slack → 开发者证言 → CLI 工具 → FAQ → 文档资源 → 深色 newsletter/footer。商业信息前置，工程深度依次展开。

## 5. 组件形态

- **CTA**：高 40px，radius 8px。主 CTA `#141413` 底 / `#FAF9F5` 字；次 CTA `#E8E6DC` 底、`#4D4C48` 字、1px `#D1CFC5` 描边。按钮没有渐变，靠明确权重分层。
- **定价卡**：381×434，白底、24px 圆角、32px padding、1px `#F0EEE6` 描边、无阴影。卡片入场有 0.4s 逐级抬升，静止后保持平面。
- **产品 Shell**：843×474、radius 20px、padding 9px，三层阴影：`rgba(10,10,10,.04) 0 0 0 1px`、`rgba(0,0,0,.024) 0 8px 24px`、`rgba(0,0,0,.04) 0 32px 80px`。它是最“浮”的元素，但阴影仍极克制。
- **FAQ icon**：小控件 radius 8px，hover/开合使用 0.25s transform + opacity。

## 6. 代码块视觉与层级设计（重点）

这套页面的代码设计分为三个明确等级：

1. **安装命令 = 行动层**：741×52 的浅色胶囊，页面同色 `#FAF9F5`、radius 12px、4px 内距。左侧是 Desktop / VS Code / JetBrains / Web / Slack 的入口切换，右侧是 `curl -fsSL https://claude.ai/install.sh | bash`，mono 17px/25.5px。它的任务是短、可复制、可入口切换，所以视觉轻、圆角大、信息少。
2. **终端 = 过程证据层**：739×648 深色 `#141413` 卡，radius 16px；35px 高的 `#30302E` header 使用 `12px 16px` padding；正文区域从卡左侧内缩 41px，mono 15px/22.5px，基础代码色 `#B0AEA5`。长 transcript 用弱灰而非高亮白，减少阅读压迫；少量蓝/珊瑚/绿/红只标记状态和语法，让“计划、工具调用、结果”的叙事可扫读。
3. **首屏产品 Shell = 产品真实感层**：白色 app 窗口 radius 20px，内部侧栏、会话列表、编辑器、composer 展示真实信息架构。它不是代码装饰，而是证明 agent 已经嵌入工作流。

这种“短命令浅色胶囊 / 长过程深色终端 / 产品界面白色窗口”的三分法，很适合开发者工具或技术型产品页：行动、过程、界面各有专属载体，不会把所有技术内容都塞进同一种黑框。

## 7. 阴影与圆角

- 圆角阶梯：4px（小标签/内联代码）→ 8px（按钮）→ 12px（命令井）→ 16px（终端）→ 20px（产品窗口）→ 24px（定价卡）→ 32px（媒体块）。尺寸越大、容器越重要，圆角越大，但最大仍控制在 32px 内。
- 阴影几乎不可见：导航浮层使用 `rgba(0,0,0,.1) 0 4px 16px`；产品 Shell 用三层低透明度大范围阴影；定价卡不用阴影。视觉优先级更多依赖底色、描边和留白。
- `1px` 暖灰描边承担大部分边界，典型为 `#E8E6DC` / `#F0EEE6`。

## 8. 动效语言

- 主 ease：`cubic-bezier(0.25, 1, 0.5, 1)`，用于 1s header 下滑、1s 页面 reveal、0.75s section reveal、0.4s 定价卡抬升。
- stagger：定价卡 delay 0 / .08 / .16s；内容 reveal delay .1 / .2 / .3 / .4 / .5s。节奏短且等差，不制造眩晕。
- hover：颜色 0.1–0.2s，背景 0.15–0.5s，box-shadow 0.2s；FAQ 图标 transform + opacity 0.25s。交互反馈快，页面级转场慢。
- 终端微动效：三点 wave `1.05s ease-in-out`，delay `.175s` / `.35s`；spark strip `5.04s steps(84, jump-none)`，把连续旋转切成机械感步进，贴合 CLI 气质。

## 9. 可复用结论

适合转化为：

- **开发者工具 / AI agent / 技术平台主题**：暖白纸底 + 墨黑文字 + 大衬线标题 + 局部深色终端，比全暗科技风更有品牌差异。
- **PPT 信息层级**：64/52/44px 衬线标题负责章节，15–17px sans 负责论证，mono 只用于命令和代码。不要让 mono 承担正文。
- **技术叙事版式**：一页放一个短命令胶囊，下一页放一张深色长过程终端；再把真实产品界面以白色 Shell 浮起，可以形成“行动—过程—产品”的三段式。
- **配色提炼**：`#FAF9F5 / #FFFFFF / #E8E6DC / #5E5D59 / #141413 / #30302E` 已足够构成主题；蓝色和珊瑚色只作为状态/焦点微点缀。
- **PPT 组件化**：24px 圆角定价卡、8px CTA、12px 命令井、16px 终端、20px产品窗口可直接对应卡片、按钮、代码块、截图容器的 token。
